How IBM can track an invoice purchase

When a buyer picks Invoice, data-popup-webhook-received doesn't fire and the browser only gets the order reference. This page runs both options side by side on a test store.

Proposed

Option 1: IBM cart id

  1. IBM adds its own cart id to the secure payload tags
  2. IBM backend gets order.payment.pending with that tag at Generate Invoice
  3. IBM front end asks its own backend by cart id

Only documented features. No FastSpring client events.

Current workaround

Option 1a: Sessions v2

  1. Browser reads fsc-paymentMethod and the session id from data-popup-event-received
  2. Browser calls Sessions v2 to get the order id
  3. Then GET /orders/{id}

Relies on event fields that aren't in the FastSpring docs.
